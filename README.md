## Проекты

### [Salon Bot](https://github.com/pavel-ai-dev/salon-bot)
Telegram-бот для мастеров маникюра и салонов красоты.
Автоматизирует записовь Bлиентов, напоминания, отзывы, портфолио и аналитику.

**Стек:** Python · python-telegram-bot · SQLite · APScheduler

**Возможности:**
- Онлайн-запись с выбором услуги, даты и времени
- Автоматические напоминания (24ч и 2ч до визита)
- Автоприглашение на повторный визит через 21 день
- Портфолио работ с фотп
- Система отзывов с рейтингом
- Экспорт записеи в Excel
- Панель управления для мастера
