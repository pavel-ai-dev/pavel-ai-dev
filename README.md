## Проекты

### Salon Bot
Telegram-бот для мастеров маникюра и салонов красоты.
Автоматизирует запись клиентов, напоминания, отзывы, портфолио и аналитику.

**Стек:** Python, python-telegram-bot, SQLite

**Возможности:**
- Онлайн-запись с выбором услуги, даты и времени
- Автоматические напоминания (24ч, 2ч до визита)
- Приглашение на повторный визит через 21 день
- Портфолио работ с фото
- Система отзывов с рейтингом
- Экспорт записей в Excel
- Панель управления для мастера

[Репозиторий](https://github.com/pavel-ai-dev/salon-bot-ai)
